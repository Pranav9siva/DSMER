# HMEM-Net: Hierarchical Multi-scale Emotional Memory Network

## Research motivation

Existing multimodal emotion recognition models mainly focus on multimodal fusion and often neglect the structured, human-like memory processes that underlie emotional perception in conversation. HMEM-Net addresses this by introducing three complementary memory modules:

1. Person Memory for long-term speaker characteristics.
2. Dialogue Memory for short-term conversational dynamics.
3. Conversation Memory for global context and topic evolution.

## Expected contribution

- Hierarchical multi-scale emotional memory
- Adaptive memory controller
- Memory-guided multimodal fusion
- Adaptive memory update engine
- End-to-end multimodal emotion recognition

## Suggested experiments

- Full model vs. ablations over each memory component
- Different memory sizes
- Different update rates
- Different loss weights
- Evaluation on MELD, IEMOCAP, MOSI, and MOSEI
